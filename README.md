# Tic Tac Toe 🎮

A simple Tic Tac Toe game made using **HTML, CSS and JavaScript**.

## Live Demo

👉 [Play Tic Tac Toe](https://niket-jain2005.github.io/tic-tac-toe/)

## Features

* Two-player game
* X and O with different colors
* Winner detection
* Draw detection
* Reset / New Game button
* Simple and responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Play

Players take turns placing **X** and **O**.
The first player to get three in a row wins. If all boxes are filled without a winner, the game is a draw.
